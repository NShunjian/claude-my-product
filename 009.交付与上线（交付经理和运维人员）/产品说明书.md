## 1. 产品是什么

**轻账** 是一款面向个人、家庭与小微生意的记账产品,提供 Web 网页、手机 App 双端入口,以及独立的运营管理后台。

它解决三类场景:

- **自己管账:** 一个人想清楚每个月钱花在哪里,坚持不下来就需要一个轻便的工具
- **一起管账:** 情侣、家庭、同住室友,需要把日常开销合并到同一本账里,看到共同收支
- **小生意记账:** 个体户、夫妻店、工作室,把生意上的进出与日常开销分开,看月度盈亏

三端产品同属一个体系,后端统一,数据互通:

| 端 | 形态 | 主要用户 |
|---|---|---|
| 轻账 Web(`frontend-react-java`) | 浏览器访问的网页版 | 偏好电脑端、屏幕大的用户 |
| 轻账 App(`uniapp-project`) | iOS / Android / 微信小程序 / H5 | 移动场景为主的用户 |
| 轻账运营后台(`admin-frontend`) | 浏览器访问的内网后台 | 平台运营人员 |

## 2. 谁在使用轻账

产品面向以下四类使用者,各自有不同的入口和权限。

### 2.1 个人用户(普通记账者)

最常见的一类。用自己的手机号注册一个账号,创建一本属于自己的账本,所有流水都记在自己账本下。日常使用的入口是手机 App 或网页版。

### 2.2 共享账本成员

被朋友、家人邀请加入"共享账本"的人。共享账本的所有流水对成员可见,但成员只能在被授权的范围内操作(例如只能记支出,不能删除账本)。成员在自己的 App 里也能切换到这本共享账,和自有账本一样使用。

### 2.3 小微生意主

把生意记账和家用记账分开的用户。可以在轻账里创建"生意账本",与"个人账本"独立管理,避免混淆。生意账本支持多账户(应收、应付、现金、银行),月度报表可一眼看到当月盈亏。

### 2.4 平台运营人员

在后台管理系统上工作的人,负责用户管理、账本审核、账目审核、分类维护、审计日志查看等。入口是独立的运营后台,与 C 端账号体系完全隔离。

## 3. 能为您做什么

按使用场景汇总产品能力,每一项在 App 和 Web 上都对应一个具体入口。

### 3.1 账本与账户

- 创建 **个人账本**、**共享账本**、**生意账本**,各自独立结算
- 在账本下添加多种类型的账户:**微信钱包**、**支付宝**、**现金**、**银行卡**、**信用卡**、**投资账户**、其他
- 账户按主题色区分,余额自动汇总到账本月度结余

### 3.2 记账

- 一笔支出:选账户、选分类、输入金额、选日期、填备注(可选)
- 一笔收入:流程同上,账户余额增加
- 一笔转账:从一个账户转到另一个账户,自动更新两边的余额,不计入月度收支

### 3.3 分类

- 系统预置常用支出和收入分类(如餐饮、交通、工资、奖金等)
- 可在分类管理页新增、停用、删除自定义分类
- 每个分类有图标与颜色,流水页和报表页会按分类视觉聚合

### 3.4 报表

- **月度报表**:按月查看收入、支出、结余,看支出按分类的占比饼图与排行,看收入按来源的分布
- **年度报表**:按年看 12 个月的支出趋势,看一年里哪些分类支出最多
- 报表支持月份切换,数据从首笔流水开始连续呈现

### 3.5 共享账本与成员

- 账本所有者可邀请其他轻账用户加入共享账本
- 成员可见账本全部流水,可按授权记账
- 账本所有者可移除成员、转让账本所有权

### 3.6 个人设置

- 修改昵称、头像、密码
- 切换界面语言(简体中文 / English / 繁體中文)
- 切换主题(明亮 / 暗色)
- 退出登录、注销账号

### 3.7 运营管理(后台)

- 查看平台总览仪表盘
- 用户管理:查看、封禁、恢复 C 端用户
- 账本管理:查看任意账本,介入违规账本
- 账目管理:基于规则或举报审核流水
- 分类管理:维护系统级预置分类
- 审计日志:查看后台操作记录

## 4. 第一次使用怎么上手

下面是从零开始使用轻账的最短路径,适用于所有新人。

### 4.1 下载与安装

- **手机用户:** 在 App Store / 应用市场搜索"轻账"下载,或在微信中打开轻账 H5 版立即体验
- **电脑用户:** 直接打开浏览器访问轻账官网,网页版无需安装

### 4.2 注册账号

1. 打开轻账,点击登录页的 **"立即注册"**
2. 输入用户名(将作为您后续登录的标识)和密码
3. 点击注册,系统将自动为您创建账号并进入首页

### 4.3 建第一本账

1. 进入"账本"页,点击 **"新建账本"**
2. 选择账本类型:**个人账本** / **共享账本** / **生意账本**
3. 输入账本名称(如"家用账"、"咖啡馆账"),选择记账货币(默认人民币)
4. 完成创建后,系统自动切换到这本新账本

### 4.4 加第一个账户

1. 进入"账户"页,点击 **"新增账户"**
2. 选择账户类型,输入账户名称(如"招商银行储蓄卡")
3. 可选:输入账户余额作为初始值
4. 保存后,账户会出现在账户列表,并计入账本总资产

### 4.5 记第一笔账

1. 在首页或顶部点击 **"快速记账"**
2. 选择 **支出** 或 **收入**
3. 选择账户、分类,输入金额、日期,可选填备注
4. 点击保存,流水立即出现在首页和流水页

### 4.6 看本月报表

1. 进入"报表"页,选择 **月度报表**
2. 默认展示本月数据,顶部有月份切换器
3. 饼图显示本月支出按分类占比,排行显示支出/收入 Top 分类

## 5. 常见业务操作说明

按操作类型逐一描述每一步的具体动作,贴近真实使用习惯。

### 5.1 切换账本

- 顶栏的 **账本切换器** 列出您有权限访问的全部账本
- 点击目标账本,全局数据(账户、流水、报表)立即刷新到该账本
- 共享账本切换后会显示成员列表入口

### 5.2 修改账户

- 账户列表点击某账户,进入详情页
- 可修改名称、图标、初始余额;账户类型创建后不可变更
- 信用卡账户可维护额度信息

### 5.3 转账

- 记账入口选择 **转账**(部分版本显示为"账户互转")
- 选择转出账户与转入账户,输入金额
- 系统自动从转出账户扣减、向转入账户增加,余额同步更新
- 转账记录不计入月度收入/支出,但会出现在流水页

### 5.4 查看历史流水

- "流水"页按日期倒序展示全部流水
- 顶部筛选器可按账户、分类、类型(支出/收入/转账)、日期范围过滤
- 长按流水可复制金额、备注

### 5.5 邀请共享账成员

- 在共享账本详情页点击 **"成员管理"**
- 输入被邀请人的轻账用户名,点击邀请
- 被邀请人在自己的账号里会收到邀请通知,确认后即可加入

### 5.6 删除账本或账户

- **账户:** 在账户详情页点击删除。若账户下存在流水,系统会提示"请先迁移或删除流水"
- **账本:** 在账本设置页点击删除。共享账本需先移除所有成员;生意账本若有月度报表,删除前会强制提示数据导出

### 5.7 修改密码

- 进入"我的" → "账号与安全" → "修改密码"
- 输入当前密码与新密码,提交后立即生效,旧 token 失效,需重新登录

### 5.8 切换语言与主题

- 进入"我的" → "外观"
- 语言:简体中文 / English / 繁體中文
- 主题:明亮 / 暗色 / 跟随系统

## 6. 核心使用流程

下面是三个最核心的端到端流程,用文字流程图说明。

### 6.1 注册到记账的完整路径

```
打开 App / 访问网页
  → 点击「立即注册」
  → 输入用户名 + 密码
  → 注册成功 → 自动登录
  → 创建「个人账本」(系统默认创建一本)
  → 新增账户(可选,也可跳过)
  → 点击「快速记账」
  → 选支出 / 收入 → 选账户 → 选分类 → 输入金额
  → 保存 → 流水展示在首页与流水页
```

### 6.2 共享账本协作流程

```
账本所有者(账主)
  → 进入共享账本 → 成员管理
  → 输入被邀请人用户名 → 发送邀请
  → 等待被邀请人确认
被邀请人
  → 收到邀请通知
  → 在账本切换器里看到「共享账本 - 邀请中」
  → 点击接受 → 共享账本出现在账本列表
  → 与自有账本一样使用(看流水、记账)
账主
  → 在成员列表可看到成员状态(已加入 / 待确认)
  → 可随时移除成员
```

### 6.3 后台运营管理流程

```
运营人员
  → 打开后台登录页
  → 用运营账号 + 密码登录(与 C 端账号体系隔离)
  → 进入仪表盘,看平台总用户数、活跃、流水量
  → 进入「用户管理」,按用户名检索,查看 / 封禁用户
  → 进入「账本管理」,按需介入违规账本
  → 进入「账目管理」,按规则或举报审核问题账目
  → 进入「分类管理」,维护系统预置分类
  → 全部后台操作记录写入审计日志,可追溯
```

## 7. 给运营管理员的说明

本节面向平台运营人员,介绍后台功能要点。

### 7.1 登录与角色

- 入口:`admin.example.com`(部署时由运维分配具体域名)
- 账号体系与 C 端账号完全隔离,运营账号仅由超管后台创建
- 角色矩阵:

| 角色 | 说明 |
|---|---|
| 超级管理员 | 所有权限,可管理其他管理员 |
| 副超级管理员 | 除超管专属设置外,其他全部权限 |
| 管理员 | 大部分管理权限,部分高危操作受限 |
| 查看者 | 只读,不能修改任何数据 |

### 7.2 关键功能

- **仪表盘:** 当日 / 本周 / 本月用户增长、活跃、流水量
- **用户管理:** 检索、查看详情、封禁、解除封禁
- **账本管理:** 检索账本、查看成员、强制解散违规账本
- **账目管理:** 按规则筛选可疑账目,审核、删除或退回
- **分类管理:** 维护系统预置分类,新增 / 停用 / 删除
- **审计日志:** 后台全部操作按时间倒序展示,可按操作人、模块检索

### 7.3 安全须知

- 运营账号登录后闲置 30 分钟自动退出
- 高危操作(封禁、解散账本、删除账目)需二次确认
- 所有敏感操作写入审计日志,无法删除

## 8. 产品背后的技术架构

本节面向交付与运维人员,简要说明技术栈,便于排查问题和对接后续开发。

### 8.1 整体架构

```
┌──────────────────┐    ┌──────────────────┐
│  轻账 Web(003)   │    │  轻账 App(007)   │
│  React 19 + TS   │    │  uni-app + Vue2  │
│  Vite 8          │    │  Pinia 2         │
└────────┬─────────┘    └────────┬─────────┘
         │                       │
         │   HTTPS / JSON       │
         └───────────┬───────────┘
                     ▼
         ┌──────────────────────┐
         │   轻账后端(005)      │
         │   Spring Boot 3.5    │
         │   Java 21            │
         │   MyBatis-Plus 3.5   │
         │   Flyway 迁移        │
         │   H2 / MySQL / PG    │
         └────────┬─────────────┘
                  │
                  ▼
         ┌──────────────────────┐
         │   轻账后台(006)      │
         │   React 19 + TS      │
         │   独立账号体系        │
         └──────────────────────┘
```

四端产品使用同一套后端 API,共享同一份数据,各自维护一套前端。运营后台与 C 端账号体系物理隔离。

### 8.2 后端核心能力

- **账号与鉴权:** JWT 颁发与校验,BCrypt 密码哈希,token 版本号机制支持旧 token 一键失效
- **权限控制:** C 端基于账本成员关系;后台基于角色 + 17 项细粒度权限码
- **数据库:** 默认 MySQL,测试环境使用 H2 内存库;表结构由 Flyway 版本化管理
- **业务错误码:** 1001-1012 用户与认证,3001-3003 账户,3010-3017 账目,5001-5003 分类,1411 后台鉴权
- **统一响应:** 所有 API 返回 `{ code, message, data }` 三段式结构;`code = 0` 表示成功,其余均为业务错误

### 8.3 前端技术栈要点

| 端 | 框架 | 状态管理 | 路由 | UI |
|---|---|---|---|---|
| Web 003 | React 19 + TypeScript 6 | Context + Hooks | React Router v7 | Tailwind v4 |
| 后台 006 | React 19 + TypeScript 6 | Context | React Router v7 | Tailwind v4 |
| App 007 | uni-app + Vue 2.7 + Composition API | Pinia 2 | uni-app 路由 | uview-plus |

## 9. 常见问题

### 9.1 注册与登录

**Q1:用户名忘了怎么办?**
A:轻账用户名是登录标识,不支持找回。请联系您的朋友或家人查询您在他们账本里的成员记录;若为运营账号,请联系平台超管重置。

**Q2:密码不对,登录一直失败?**
A:确认大小写、空格、输入法全角半角。若确认无误,可通过"修改密码"页重置(需已知旧密码)。

**Q3:登录提示"操作失败,请重试"怎么办?**
A:通常是网络问题。请检查网络后重试;若持续出现,可能是账号被后台封禁,请联系客服。

### 9.2 账本与账户

**Q4:能建多少本账?**
A:不限制。常见组合:个人一本家用账 + 一本旅行账 + 共享账本若干。

**Q5:账户类型创建后能改吗?**
A:不能。如果选错了类型,需要删除后重建。删除账户前需先清空该账户下的流水。

**Q6:为什么删不了账户?**
A:账户下若有流水,系统会拒绝删除,需要先把流水删除或迁移到其他账户。

### 9.3 记账

**Q7:记错了一笔账怎么办?**
A:流水列表找到该笔 → 长按 / 点击 → 选择"编辑"或"删除"。

**Q8:转账会被计入月度收支吗?**
A:不会。转账只是两个账户之间的内部资金移动,不会重复计入月度统计。

**Q9:能批量导入历史账单吗?**
A:Web 版支持 Excel 导入(App 版暂未开放)。在流水页选择"导入"即可,支持常见银行账单格式。

### 9.4 报表

**Q10:报表数据是实时更新吗?**
A:是。任何一笔记账、保存、修改后,所有相关报表立即反映。

**Q11:报表里的月份切换能看历史吗?**
A:可以。最早可看到您第一笔记账所属月份,一直到现在。

### 9.5 共享账本

**Q12:邀请的人找不到怎么办?**
A:确认被邀请人已注册;邀请需输入对方的轻账用户名,不是手机号或邮箱。

**Q13:退出共享账本后还能看到之前的流水吗?**
A:退出后,共享账本从您的账本列表移除,但您之前已经看到的流水仍可在本机历史记录中保留。账本所有者拥有最终数据。

### 9.6 后台相关

**Q14:运营账号和 C 端账号能互登吗?**
A:不能。两者是完全独立的账号体系,登录入口、域名、数据库均分离。

**Q15:后台操作会被记录吗?**
A:会。所有后台操作都进入审计日志,按时间、操作人、模块、对象类型可检索。

## 附录 A · 名词解释

| 名词 | 解释 |
|---|---|
| **账本(Book)** | 一组账户和流水的逻辑集合,用户可建多本账本并在之间切换 |
| **账户(Account)** | 账本下的资金存放单位,对应一张银行卡、一个钱包或一笔现金 |
| **流水(Record)** | 一笔具体的收入、支出或转账记录 |
| **分类(Category)** | 给流水打的标签,用于按维度汇总;系统预置 + 用户自定义 |
| **报表(Report)** | 按时间维度(月 / 年)对账本内的流水做统计汇总 |
| **共享账本** | 多人都可记账的账本,适用于家庭、情侣、室友 |
| **生意账本** | 专门为个体经营者设计的账本,与家用账本独立结算 |
