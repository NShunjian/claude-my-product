## 二、产品概述

### 2.1 产品定位

**轻账** —— 一款轻量级个人/家庭财务管理工具，主打"3秒完成一笔记账"，让记账像发朋友圈一样简单。

| 维度 | 描述 |
|------|------|
| **一句话定位** | 最轻的账本，最快的记账 |
| **核心价值** | 极简操作 × 清晰报表 × 零学习成本 |
| **差异化** | 比随手记更轻，比 Excel 更智能，比备忘录更专业 |
| **Slogan** | 记账，轻轻松松 |

### 2.2 产品目标

| 阶段 | 目标 | 衡量指标 |
|------|------|----------|
| **V1.0 上线** | 跑通核心记账闭环 | 次日留存 ≥ 40%，7日留存 ≥ 20% |
| **V1.1 迭代** | 提升留存与粘性 | 月活 ≥ 5万，人均月记账 ≥ 30笔 |
| **V2.0 进阶** | 建立财务健康管理闭环 | 付费转化率 ≥ 5%，NPS ≥ 40 |

### 4.2 功能详细说明

#### P0 —— 快速记账（核心路径）

| 字段 | 说明 | 规则 |
|------|------|------|
| **金额** | 必填，数字键盘输入 | 支持 0.01~999,999.99，最多2位小数 |
| **分类** | 必填，默认选中上次使用的分类 | 支持支出/收入切换，长按可设为默认 |
| **备注** | 选填，文字描述 | 最多50字 |
| **日期** | 选填，默认当天 | 支持往前补记30天 |
| **账户** | 选填，默认上次使用的账户 | 仅展示已启用的账户 |

**交互流程**：

```
打开App → 首页底部"+"按钮 → 数字键盘输入金额 → 选择分类 → (可选)填备注/改日期/选账户 → 点击"完成" → 记账成功（Toast提示）→ 自动清空等待下一笔
```

**关键体验指标**：
- 从打开 App 到完成一笔记账：≤ **3秒**（金额+分类+完成）
- 记账成功反馈：轻量 Toast + 金额数字跳动动画
- 支持连续记账：完成后不关闭键盘，直接输入下一笔

#### P1 —— 账户管理

| 功能 | 说明 | 优先级 |
|------|------|--------|
| **预设账户** | 微信支付、支付宝、现金、银行卡(储蓄)、信用卡 | P1 |
| **账户列表** | 展示各账户名称、图标、余额 | P1 |
| **新增账户** | 自定义账户名称 + 选择图标 + 初始余额 | P1 |
| **编辑/删除** | 修改账户信息，删除时需确认且无关联账目 | P1 |
| **账户筛选** | 按账户筛选流水明细 | P2 |

**规则**：
- 账户余额 = 初始余额 + 关联收入 - 关联支出（自动计算）
- 删除账户时，若有关联账目则提示"该账户有N笔记录，无法删除"
- 至少保留1个账户

### 5.3 配色方案

- **信任感**：金融产品需传递安全、可靠的心理暗示 → 偏冷色调

- **辨识度**：分类图标颜色区分明确 → 高饱和度点缀色

## 六、数据模型设计

### 6.1 核心实体关系

```
用户(User) ──1:N──> 账本(Book)
账本(Book) ──1:N──> 账目(Record)
账本(Book) ──1:N──> 账户(Account)
账目(Record) ──N:1──> 分类(Category)
```

### 6.2 数据表结构

#### 账目表（records）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | UUID | ✅ | 主键 |
| book_id | UUID | ✅ | 所属账本 |
| type | Enum | ✅ | `expense` / `income` |
| category_id | UUID | ✅ | 分类ID |
| amount | Decimal(12,2) | ✅ | 金额 |
| account_id | UUID | ✅ | 关联账户 |
| note | String(50) | ❌ | 备注 |
| record_date | Date | ✅ | 记账日期 |
| created_at | Timestamp | ✅ | 创建时间 |
| updated_at | Timestamp | ✅ | 更新时间 |

#### 账户表（accounts）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | UUID | ✅ | 主键 |
| book_id | UUID | ✅ | 所属账本 |
| name | String(20) | ✅ | 账户名称 |
| icon | String | ✅ | 图标标识 |
| initial_balance | Decimal(12,2) | ✅ | 初始余额 |
| is_default | Boolean | ✅ | 是否默认账户 |
| sort_order | Integer | ✅ | 排序权重 |
| created_at | Timestamp | ✅ | 创建时间 |

#### 分类表（categories）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | UUID | ✅ | 主键 |
| type | Enum | ✅ | `expense` / `income` |
| name | String(10) | ✅ | 分类名称 |
| icon | String | ✅ | 图标标识 |
| color | String | ✅ | 颜色色值 |
| is_preset | Boolean | ✅ | 是否预设分类 |
| sort_order | Integer | ✅ | 排序权重 |

## 七、非功能需求

| 维度 | 要求 | 说明 |
|------|------|------|
| **性能** | 冷启动 ≤ 2s，记账操作 ≤ 300ms | 本地优先，数据存客户端 |
| **存储** | 本地 SQLite，支持iCloud/云端同步(V1.1) | V1.0 纯本地存储 |
