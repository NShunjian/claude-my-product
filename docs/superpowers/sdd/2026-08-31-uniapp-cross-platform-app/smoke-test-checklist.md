# 跨端冒烟测试清单

> 适用平台：**H5**（浏览器）/ **mp-weixin**（微信小程序）/ **App**（iOS & Android）
> 测试顺序：按清单顺序执行，前置步骤失败则停止。

---

## 平台无关前置条件

- [ ] 后端服务已启动，接口可访问
- [ ] 测试账号已创建（默认演示账号或自建）
- [ ] 各平台编译产物已生成（`npm run dev:h5` / `dev:mp-weixin` / `dev:app`）

---

## H5（浏览器）

**启动：** `npm run dev:h5` → 浏览器打开 `http://localhost:5173`

### 1. 登录 / 鉴权

- [ ] 未登录时访问根路径，自动跳转 `/pages/login/index`
- [ ] 输入正确账号密码，点击登录，提示"登录成功"并跳转首页
- [ ] 输入错误密码，提示错误信息，停留在登录页
- [ ] 登录成功后 token 存入 storage，刷新页面保持登录态

### 2. 首页（pages/index/index）

- [ ] 顶部显示当月收支汇总（本月收入 / 本月支出）
- [ ] 下方显示 5 条最近流水记录
- [ ] 每条流水显示：金额、分类图标/名称、账户、日期
- [ ] 「记一笔」按钮可见，点击后弹出选择：记支出 / 记收入
- [ ] 底部 tabBar（首页/流水/报表/我的）切换正常

### 3. 记一笔（pages/record/expense & pages/record/income）

- [ ] 进入页面，默认填入当日日期
- [ ] 金额输入：键盘弹出数字键盘，输入正确数值
- [ ] 账户选择：点击 picker，弹出选项列表，选择账户后显示选中名称
- [ ] 分类选择：点击 picker，弹出分类列表（带图标），选中后显示分类名
- [ ] 备注输入：可填写中文/英文/emoji
- [ ] 保存：点击保存按钮，提示"保存成功"，返回上一页
- [ ] 返回首页后，新流水出现在列表顶部

### 4. 流水（pages/transactions/index）

- [ ] 列表默认显示全部流水，按日期倒序
- [ ] 每条记录显示：金额、分类、账户、日期
- [ ] 支持下拉刷新（重新请求列表）
- [ ] 支持上拉加载更多（分页）
- [ ] 点击单条记录，可编辑：修改金额/分类/账户/备注后保存
- [ ] 删除：点击删除，确认后流水从列表移除

### 5. 报表（pages/reports/monthly & pages/reports/yearly）

- [ ] 月报：顶部切换月份，可选前后月份
- [ ] 折线图（LineChart）：显示每日收支趋势，hover/touch 显示 tooltip（数值+日期）
- [ ] 环形图（DonutChart）：显示各分类支出占比，图例清晰
- [ ] 年报：切换年份，折线图展示 12 个月支出趋势
- [ ] 空数据时图表区域显示占位提示

### 6. 账户（pages/accounts/index & pages/accounts/new）

- [ ] 账户列表页显示所有账户：名称、余额、图标/颜色
- [ ] 新建账户：填写名称、初始余额、选择颜色/图标，保存后列表更新
- [ ] 编辑账户：修改名称/颜色，保存后即时反映
- [ ] 删除账户：确认后从列表移除（流水中的账户显示不变）

### 7. 账本（pages/books/index & pages/books/members）

- [ ] 账本列表显示所有账本及成员数量
- [ ] 成员管理页显示当前账本成员列表
- [ ] 新增成员：输入名称/角色，保存后列表更新

### 8. 设置 / 我的（pages/settings/index）

- [ ] 顶部显示用户头像（默认头像或已上传头像）
- [ ] **主题切换**：切换「浅色 / 深色 / 跟随系统」，页面主题实时变化
- [ ] **语言切换**：切换「简体中文 / 繁體中文 / English」，文案立即更新
- [ ] **分类管理**：进入后支持新增/编辑/删除分类，分类图标可选
- [ ] 退出登录：确认后清除 token，返回登录页

### 9. 编辑资料（pages/profile/edit）

- [ ] 显示当前头像，点击可选择本地图片更换头像
- [ ] 修改昵称后保存成功

## mp-weixin（微信小程序）

**启动：** `npm run dev:mp-weixin` → 微信开发者工具打开 `dist/dev/mp-weixin/`

> 小程序验收清单与 H5 相同，以下仅标注**平台特有**检查项。

### 特有检查项

- [ ] **域名白名单**：开发阶段在微信开发者工具 → 详情 → 本地调试 → 勾选「不校验合法域名」
- [ ] ** picker 组件**：所有 picker（账户选择、分类选择、月份选择）的 `range-key` 正确配置，显示文本而非 `[object Object]`
- [ ] ** picker 索引取值**：`e.detail.value` 为数组下标，切换选项后值正确映射到数据
- [ ] ** token 失效**：模拟 token 过期，接口返回 401，自动跳转登录页
- [ ] **启动页**：小程序启动后首屏正常，无白屏
- [ ] **tabBar 图标**：使用平台默认图标（自定义图标未实现，属已知差异）
- [ ] **LineChart tooltip**：`touches[0].x/y` 在真机上可能异常，测试时关注 tooltip 是否正确显示；若异常需使用 `uni.createSelectorQuery` 获取坐标

### 登录 / 首页 / 记一笔 / 流水 / 报表 / 账户 / 账本 / 设置 / 编辑资料

- [ ] 同 H5 各对应页面检查项

## 已知平台差异汇总

| 问题 | 平台 | 状态 | 说明 |
|------|------|------|------|
| picker `range-key` 缺失 | mp-weixin | 已修复 | 需确保所有 picker 组件配置了 `range-key` |
| picker `e.detail.value` 索引映射 | mp-weixin | 需关注 | value 是数组下标，不是对象；多列 picker 需注意结构 |
| LineChart tooltip 坐标 | mp-weixin / App | 需关注 | `touches[0].x/y` 在部分机型不准，建议使用 `uni.createSelectorQuery` 获取真实节点坐标 |
| `document.createElement` 头像上传 | App（Android） | 已修复 | 现已改用 `uni.chooseImage`，注意部分 Android webview 仍可能拦截 |
| 自定义 tabBar 图标 | 全平台 | 已知差异 | 目前使用平台默认图标，有设计稿图标未实现 |
| H5 类型检查报错 | H5 | 预已知 | alias 相关预现有问题不影响运行，仅类型检查失败 |
